## 📌 Overview
This project features an **Embedded Real-Time System** designed for automated room occupancy monitoring and secure access control in an event hall. The system tracks people entry and exit in real time, manages maximum venue capacity, and automatically blocks entry when the capacity limit is reached.

---

## 🛠️ Key Features & Architecture
- **Real-Time Occupancy Monitoring:** Continuous sampling of input sensors to accurately track the number of individuals inside the venue.
- **Automated Access Control:** Implemented safety logic to instantly block entry gates/doors when maximum capacity is reached.
- **User & Status Interface:** Designed a real-time interface for continuous sensor sampling, occupancy management, and live user information display (LCD/LED/Serial).
- **Embedded C/Assembly Implementation:** Developed efficient, low-level firmware targeting an ARM microcontroller architecture.

## 🚀 How to Run & Build
1. Open the project workspace in your ARM-supported IDE (e.g., Keil uVision, IAR, or Eclipse-based toolchain).
2. Compile the source code in the `src` directory.
3. Flash the binary file onto the ARM microcontroller board and monitor real-time outputs via the debugging terminal.
